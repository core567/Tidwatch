# 新 3D 河流场景需求规范（SCENE_REQUIREMENTS）

目标：用 Three.js / React Three Fiber **程序化**生成一段更真实的汉江中下游河流场景，
替换当前简化的几何示意，作为 TideWatch 数字孪生底座。全部代码生成，不使用 Blender 模型文件。

---

## 1. 总体

- 视角：第三人称俯瞰为主，支持轨道旋转/缩放/平移；A/B/C 节点相机飞行必须保留（见集成指南）。
- 尺度：河段约 60–80 个世界单位，水面宽度参考现有 `WATER_WIDTH=4.6`、`BANK_WIDTH=13`，可按真实感调整但要成比例。
- 风格：写实偏克制，青绿水体 + 缓起伏河谷 + 节制的科技标注；**禁止**卡通化、霓虹、大面积发光。
- 坐标：Y 轴向上；河沿 XZ 平面弯曲；上游在 -X 方向、下游在 +X 方向的现有约定可沿用。

## 2. 地形

- 程序化高度场（多层 value/simplex 噪声，确定性种子，刷新不抖动）。
- 河道处下沉形成河谷，向两岸缓抬升为丘陵/阶地；近河岸有滩涂与缓坡。
- 颜色按高程/坡度分带（河床、滩地、植被、丘陵），可用顶点色或程序化纹理，避免贴图拉伸。
- 必须能与水面边缘自然衔接，不穿插、不露明显缝隙。

## 3. 河流与水体

- 沿中心线 CatmullRom 或自定义曲线生成带状水面（沿用 `RIVER_CURVE` 思路，可加密控制点让弯曲更自然）。
- 水面有轻微法向流动（法线贴图滚动或顶点微波），低耗，移动端可降级。
- 半透明 + 环境反射适度；体现流向（可选低速漂浮纹理/粒子，密度极低）。
- 保留 `buildWaterGeometry` 这类**纯几何函数**的可测试性（输入曲线/宽度 → BufferGeometry），便于单元测试。
- 水质不随模型变色表达污染；超标只通过 UI 数据与节点告警体现。

## 4. 植被与岸线

- 用 InstancedMesh 批量放置草、灌木、乔木（避免每棵树一个 Mesh）。
- 分布遵循距河道距离与高程，水中不长树；数量可控（如 300–1500 株档），保证帧率。
- 颜色低饱和，不抢节点视觉焦点。

## 5. 监测设施（A/B/C）

每个断面（reach-a/b/c）一个监测节点，建议包含：
- 小型监测平台/桩台/岸基站（盒子、支柱等基础几何组合即可）。
- 一个状态灯/指示色，由 `onlineStatus` 驱动：ONLINE 青绿、STALE 橙、OFFLINE 灰。
- 异常断面（在 `abnormalReachIds` 中）显示红色脉冲光圈（沿用现有逻辑）。
- 始终可见的文字标签（可用 drei `<Html>`，但注意数量与遮挡；也可 Sprite 文本）。
- 点击命中区域要足够大，点击触发 `onSelectNode(reachId)` 并飞行。

## 6. 科技标记与信息层（克制）

- 节点光柱/环形扫描最多 1–2 层，不要全河道铺满发光线。
- 可选：节点间细虚线表示传播关注方向；不要画成确定性因果箭头。
- 不增加额外业务数据；所有标记来自 reachId / onlineStatus / abnormalReachIds。

## 7. 相机与交互

- 保留 zustand `cameraStore.flyTo('overview'|'reach-a'|'reach-b'|'reach-c')`。
- 飞行用缓动插值 position+target；节点局部视角位于河侧上方俯视（参考 stationViews.ts 自动计算）。
- OrbitControls 阻尼开启；限制最大俯角与缩放范围，避免穿地或飞出场景。
- 切换节点不重建场景。

## 8. 坐标与数据规范

- 不得硬编码真实经纬度高程；当前为逻辑示意坐标。节点 ID 固定 reach-a/b/c。
- 真实坐标核实后，仅替换曲线/锚点定义；相机视角与节点逻辑应自动适配。
- 时间、水质、事件等数据来自主项目 API，场景内不伪造数值。

## 9. 性能目标（桌面）

| 分辨率 | 目标帧率 |
|---|---|
| 1920×1080 | ≥ 55 fps（中端独显/核显参考） |
| 1440×900 | ≥ 50 fps |

- draw call 尽量合并：地形 1–3、水面 1、植被各 1–3 个 InstancedMesh。
- `dpr={[1, 1.8]}` 左右，阴影贴图 ≤ 2048；远处用雾裁剪（现有雾 60–150）。
- 几何体/材质在卸载时 dispose，避免反复进出页面内存泄漏。
- 提供降级：WebGL 不可用时沿用 `WebGLErrorBoundary` 提示。

## 10. 交付与验收

- 在独立包 `npm run dev` 可看新场景，A/B/C 点击飞行、全景复位、mock 在线/异常状态正确。
- 保留纯几何函数并补 node:test（如曲线点数、宽度、节点 t 单调：A<B<C）。
- 提供替换说明：哪些文件覆盖主项目、哪些新增；不修改后端与 AI/业务逻辑。
- 截图（1440 与 1920）各一张全景 + 节点聚焦。
