# P11 语音现场感知

## 能力边界（重要）

- 使用微信「同声传译」插件（`WechatSI`）做现场语音转文字，转写结果可追加到巡检观察记录。
- **插件不可用时（开发者工具未配置、未真机授权、识别失败）自动降级为手动输入**，
  并在记录上标记来源：
  - `VOICE_PLUGIN`：语音转写
  - `MANUAL_FALLBACK`：手动输入
- 系统**绝不伪造语音识别结果**；语音仅辅助记录，不参与事件状态机，
  最终结论仍由巡检人员人工确认。

## 启用步骤（真机/工具）

1. 微信公众平台 → 小程序后台 → 设置 → 第三方设置 → 添加插件「微信同声传译」（appId: `wx069ba97219f66d99`）。
2. `app.json` 增加：

```json
{
  "plugins": {
    "WechatSI": { "version": "0.3.6", "provider": "wx069ba97219f66d99" }
  }
}
```

3. `project.config.json` 中勾选「使用插件」。
4. 真机首次使用会请求录音权限（`scope.record`）。

未完成上述配置时，记录页「按住说话」会立即提示降级，不影响正常手动填写与提交。

## 交互

- 现场记录页：按住「说话」开始，松开发送；识别文本追加到观察记录并标注来源。
- 识别失败/无内容：提示手动输入，不写入任何虚构文本。
