# 微信小程序实时通道与现场感知配置

## 一、WebSocket 配置（已接通）

小程序登录成功后建立**全局唯一** WS 连接（`utils/ws.ts`），
接收任务派发/状态变化、事件、盲区等推送，重连后用 `resumeFrom` + REST 快照补偿。

### 开发者工具模拟器（本地 ws://）
- `config/env.ts` 中 `HOST='127.0.0.1'` 即可（模拟器与电脑同机）。
- 开发者工具 → 详情 → 本地设置：勾选「不校验合法域名、web-view、TLS 与 HTTPS 证书」。

### 真机调试（局域网 ws://）
1. `config/env.ts` 的 `HOST` 改为**电脑的局域网 IP**（与手机同一 WiFi），如 `192.168.1.100`，不能用 localhost。
2. 电脑防火墙放行后端端口（默认 8000）。
3. 手机与电脑同一局域网；开发者工具真机调试 2.0 对未备案 ws:// 支持有限，
   如连不通请改用「真机调试 1.0」或在工具内勾选“不校验域名”。
4. 后端需 `MQTT_ENABLED=true` 才会产生实时业务消息；WS 连接本身与 MQTT 无关。

### 正式环境（wss://）
- 必须使用**已备案域名 + 合法 TLS 证书**的 `wss://域名/api/ws`。
- 在小程序后台「开发管理 → 服务器域名 → socket 合法域名」添加 wss 域名。
- 把 `buildWsUrl` 改为 `wss://`。不在本次竞赛 V1.0 范围。

### 连接生命周期
- 登录成功 / App 冷启动已登录 / 回前台：`wsClient.connect()`（单例，重复调用不建第二条）。
- 退出登录：`wsClient.logout()`（断开、清 resume、不重连）。
- Token 失效：停止重连并回到登录页。
- 页面卸载只取消订阅，不关闭全局连接；多页面共享一条连接。

## 二、语音 ASR/TTS 插件可行性核实（重要）

> 结论先行：**当前不写入未经验证的插件 AppID，默认使用手动输入降级方案。**

### 需在微信公众平台核实的事项（需小程序主体账号，开发环境无法替你确认）
1. 「微信同声传译」插件（provider `wx069ba97219f66d99`）当前是否仍可申请、是否对**个人/测试号**开放。
   - 该插件历史上**主要面向已认证的小程序**，未认证测试号可能无法在 app.json 中启用。
2. 插件提供的能力：`plugin://WechatSI/record`（ASR 语音识别）可用；
   **TTS 语音合成**为另一接口（`textToSpeech`），需确认当前版本仍提供且权限范围。
3. 真机限制：首次需 `scope.record` 录音授权；插件对基础库版本有要求；
   开发者工具模拟器对插件音频支持不完整，应以真机为准。
4. 审核与合规：录音需在隐私协议中声明。

### 当前实现状态
- `services/voice.ts` 已封装插件调用，但**惰性加载、缺插件即降级**：
  - 插件可用 → `VOICE_PLUGIN`（语音转写）；
  - 插件缺失/识别失败 → `MANUAL_FALLBACK`（手动输入），绝不伪造识别文本。
- 记录页「按住说话」在未配置插件时会提示降级，核心巡检/提交流程不受影响。

### 若核实后确认可用，启用步骤
1. 小程序后台添加「微信同声传译」插件并通过。
2. `miniprogram/app.json` 增加：
   ```json
   "plugins": { "WechatSI": { "version": "0.3.6", "provider": "wx069ba97219f66d99" } }
   ```
3. 真机验证录音权限与识别结果；TTS（如需要）再单独接入，不阻塞 V1.0。
