# 样例数据说明

## wuhan_surface_water_2026-07_hanjiang.csv

来源：武汉市生态环境局《2026年7月武汉市地表水环境质量状况》
（发布机构：武汉市生态环境监控中心，发布日期：2026-09-07），
原文：<https://hbj.wuhan.gov.cn/fbjd_19/xxgkml/hjtj/202609/t20260907_2844194.html>

仅摘录汉江武汉段 3 个断面（新沟*、宗关、龙王庙）在原报告表 1 中的行，
字段按原报告口径保留（月度水质类别，非连续监测值）：

- 新沟*：功能类别 Ⅲ，水质现状 Ⅱ，达标，同比稳定；`*` 为原报告的入境断面标记；
- 宗关：水质现状 Ⅱ，达标，同比稳定；
- 龙王庙：水质现状 Ⅱ，达标，同比好转。

用途：官方公开历史资料导入的已核实样例。不得插值为小时级连续曲线，
不得描述为实时监测数据；三个断面仅为 A/B/C 逻辑点的候选，坐标与上下游待核实。
